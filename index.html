Charges (Disclosure section B)
Enter only charges that are lawful and actually applicable. Unused rows print NONE. "Deducted" means withheld from the released proceeds. Finance / non-finance class per row is set under Settings.

Co-maker (solidary)
A co-maker is printed on the Promissory Note only if named here, and must expressly tick the solidary-liability consent before signing.
Security & optional forms
Collateral (Form A)
Schedule B (custody receipt) prints when any asset is in the Secured Creditor's custody.
Cash security deposit (Form B)
The deposit is recorded as Held once the agreement is signed. Application or refund is documented with the post-execution acknowledgments below.
Surety / guarantor
A surety binds himself solidarily (no excussion); a guarantor is subsidiary. The person must sign the separate agreement and, for a suretyship, tick the solidary consent. A contact person or character reference is not a surety.
